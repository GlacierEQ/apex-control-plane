## Projection law

Portable copies are **read-only projections** of APEX source state.

They may:

- compress wording for a smaller context window;
- map tool names to platform-specific equivalents;
- add transport instructions required by a platform;
- retrieve memories or source references;
- expose current capability limits;
- preserve source identifiers and version information.

They may not:

- rewrite the Operator's objective;
- reduce the requested ambition because a model prefers a smaller task;
- create a competing approval layer;
- convert an adapter, memory store, registry, or governance artifact into project authority;
- silently weaken Jack's execution loop;
- claim source state that was not retrieved or verified;
- promote a derived projection into the source of truth.
