# AKOS Epistemic Lattice

Donor provenance: `continuous-control-plane-v1` @ `75a29e3f22c692dcb9e2a3b137ad6f3970682058`, especially `docs/CONTINUOUS_CONTROL_PLANE.md`.

This is a selective donor harvest. It preserves the donor's useful HOW-TO-KNOW mechanism without importing its stale single-orchestration-authority or universal-source-of-truth claims. Current explicit Operator instruction remains controlling for active execution; owning providers remain authoritative for provider facts; domain runtimes retain their own authority.

## Epistemic loop

```text
PERCEIVE
 -> PROVENANCE
 -> CLASSIFY
 -> MODEL
 -> FALSIFY
 -> VERIFY
 -> LEARN
 -> REENTER
```

The lattice shapes how observations become claims and how claims are challenged before stronger evidence-state promotion. It is an epistemic mechanism, not an approval gate, sovereign coordinator, or replacement for domain ownership.

## Operating application

1. Recover source-bearing context before reconstructing state.
2. Preserve provenance through classification and modeling.
3. Falsify material claims before promoting them beyond their receipts.
4. Verification strengthens an evidence label; missing verification does not freeze unrelated authorized work.
5. Learned deltas re-enter the mesh so later workers compound rather than restart.
6. Before destructive or high-blast-radius mutation, inspect structural indirection, dependents, recovery routes, and downstream consequences.
7. Uncertainty routes to retrieval, experiment, or verification rather than automatic minimization.

## Anti-flattening constraints

- No summary, checkpoint, memory, manifest, or worker output acquires Operator authority merely by restating it.
- No shared substrate becomes a universal authority over provider-native facts or domain-owned state solely because it carries continuity data.
- No branch, newest artifact, or current integration surface proves older donor state has zero unique contribution.
- The strongest coherent compatible change is preferred over smallest-change minimalism; selective harvest must preserve stronger current behavior.
