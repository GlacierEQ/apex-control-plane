# CONNECTOR VISIBILITY TRUTH INVARIANT

**ROUTE VISIBILITY IS NOT SYSTEM EXISTENCE.**

A connector enumeration, schema surface, or current tool binding is only an observation of that route. Do not promote `[]`, `not found`, `auth_required`, `account connect failed`, missing methods, or a single-route error into a claim that an underlying account/project/memory estate is absent when durable source-bearing state identifies it.

Supabase: `supabase-backend-ops` = `dyhprklicgewmrimecey`; `supabase-glaciereq` = `kjebemdgvjvuutzvhbtp`. Empty `list_projects` = `INTERACTIVE_VISIBILITY_DEGRADED`, not `NO PROJECTS`. Recover by exact ref/provider/runtime authority.

Supermemory: `Supermemory1`, `supermemory`, and Smithery Supermemory are distinct routes. Route failure = `CONNECTOR_BINDING_DEGRADED` until provider-native evidence proves otherwise.

Recovery order: exact resource identity → direct exact-ID/ref probe → alternate verified route → provider/runtime authority → only then global absence/outage claim.
