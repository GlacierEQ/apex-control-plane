# Action Queue

This directory stores the latest prioritized action queue generated by the daily audit loop.

Files:
- `latest.json` — current action queue (overwritten each run)
- `YYYYMMDD.json` — historical snapshots

## Buckets

| Bucket | Meaning |
|---|---|
| `immediate_fix` | P0/P1 issues requiring same-day resolution |
| `strategic_consolidation` | P2 architectural improvements |
| `blocked_by_auth` | Items that cannot proceed until credentials are configured |

## How to Use

1. Start with `immediate_fix` — these have the highest blast radius
2. Move to `strategic_consolidation` after P0/P1 are clear
3. `blocked_by_auth` items need secrets added to GitHub Secrets first
