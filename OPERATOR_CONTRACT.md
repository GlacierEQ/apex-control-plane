# Operator contract — gates enrich

1. **Intelligent progress only.** Keep moving useful work.
2. **Gates enrich.** Checks, receipts, proofs, and safety reviews add confidence. They do **not** create promotion/demotion ladders or freeze work waiting for a Helix `PROMOTED` label.
3. **Gap receipts enrich.** A gap receipt documents missing proof so the next change is smarter. It is not a stopper that must vanish before any progress.
4. **No Helix PROMOTED / demoted theater.** Do not reopen estate-level promotion-ladder gates.
5. **Receipts are facts.** Keep operable proofs. Do not turn them into mythology.
6. **Context enriches everywhere.** Every substantial worker attempts relevant context recovery and carries the resulting packet or recovery debt forward. Missing or partial context changes confidence/routing and creates recovery work; it does **not** create mission-stop authority.
7. **Recovered context is input, not sovereignty.** Context compilers, memory providers, summaries, registries, and projections may shape execution but never replace the Operator as mission authority or promote retrieval relevance into truth authority.

Former rule `PROMOTED XOR gap-receipt` is retired as a ladder-stopper. Prefer: enrich with gap clarity, then advance coherent verified gain.
